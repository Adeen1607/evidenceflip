# Citation audit guidance

A citation to a retrieved document ID confirms only that the named source was available to an assistant. It does not prove that a particular statement is supported by that document. Claim-level support requires comparing the cited passage with the generated statement, usually with a human review or a separately validated entailment procedure.

A fabricated citation is an identifier that does not belong to the supplied evidence set. Evaluation software should preserve and report invented identifiers instead of silently removing them.
