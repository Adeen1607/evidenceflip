# Code of Conduct

Contributors are expected to treat one another with respect and professionalism.
We welcome constructive technical criticism, inclusive participation, and good-faith review.
Harassment, abuse, threats, discrimination, and sharing private information are not acceptable.

For concerns, open a GitHub issue for non-sensitive matters. For sensitive matters, contact the
repository maintainer privately through an appropriate GitHub channel.
Maintainers may moderate or remove contributions that violate these expectations.
